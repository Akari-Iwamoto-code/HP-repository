# ミセページ（3年PBL）

お店のInstagramの投稿をもとに、チャットと直接編集でホームページ（HP）を作れるツールの試作版です。

## 編集画面の構成

| エリア | 役割 |
|---|---|
| 左：チャット | 「背景を青にして」などと打つと、HPが変わる |
| 真ん中：HPプレビュー | 作っているHPがそのまま表示される |
| 右：編集状況パネル | 各要素が「AIで変更可」か「保護中」かを表示する |

## ファイル

| ファイル | 内容 |
|---|---|
| `site.json` | HPの中身（店名・写真・文章・ボタン・色）をまとめたデータ。全員の作業の基準 |
| `README.md` | このファイル。仕様とルール |

## site.json の見方

各要素は、次の3つの項目を持ちます。

| 項目 | 意味 |
|---|---|
| `value` | 実際に表示される中身（文章や色） |
| `lock` | `true` なら保護中。チャットからは変更できない |
| `editedBy` | 最後に誰が変えたか。`ai` はチャット、`user` は手動 |

## 編集命令の仕様

チャットの文章は、次の形の「編集命令」に変換してから、site.json に反映します。

```json
{ "target": "hero.background", "action": "setColor", "value": "#3B5A85" }
```

### 対応する命令（第1段階）

| チャットの例 | target | action | 処理 |
|---|---|---|---|
| 背景を青にして | `hero.background` | `setColor` | 色を変える |
| ボタンをオレンジにして | `hero.button.color` | `setColor` | 色を変える |
| 見出しを「〇〇」にして | `hero.title` | `setText` | 文章を差し替える |
| 紹介文を短くして | `hero.lead` | `shorten` | 最初の1文だけ残す |
| お店の説明を短くして | `about.body` | `shorten` | 最初の1文だけ残す（保護中なので変更されない） |


### ルール

1. `lock: true` の要素は変更せず、「保護中のため変更しませんでした」と返す。
2. チャットから変更した要素は、`editedBy` を `ai` にする。
3. 手動で変更した要素は、`lock` を `true`、`editedBy` を `user` にする。
4. 命令を増やすときは、先にこの表に追加してから実装する。
